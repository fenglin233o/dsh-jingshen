# 精神 0.4.0

fenglin 的 DeepSeek Harness 个人助手，目标宿主为 `0.2.2-rc.5`。

- 点击画幅里的小肥鱼展开通讯窗。打字、观看和休眠对应真实活动，表情可由精神选择。
- 主会话的答复都经过表达判断。其他有精神参与的会话，实际发布的回复旁会显示“精神”。
- 精神可以采纳、修订、继续表达或沉默。在完全访问下，没有新消息时也能单独告诉你一件事。新旧工作会话共享已有判断和意向。
- 通话时小肥鱼放大居中，开口可以打断播放。摄像头、屏幕和视频可在本机连续识别。语音需要就绪的识别与合成服务。
- 沿用原来的状态目录和 profile 可接续 0.2.0 或 0.3.0 的主会话、权限及已有工作。本版本安装后有一个精神预设。

```sh
dsh plugin --profile spirit add /绝对路径/dsh-jingshen-0.4.0.tgz
```
