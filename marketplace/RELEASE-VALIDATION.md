# 精神 0.4.6 发行包复核

包名为 `dsh-jingshen`，作者 fenglin。宿主为 DeepSeek Harness `0.2.2-rc.5`，要求 Node.js 24.9+。

标准包提供宿主与客户端构建产物、小肥鱼、视觉模型和支持句内中英混说的本机 X-ASR 识别模型。可选的 `dsh-jingshen-0.4.6-local-voice-assets.tgz` 提供 PrimeTTS 权重、许可证与 ONNX Runtime Web CPU 运行时，解压到同一插件目录即可使用。

本次构建、测试、升级、主会话和电话的验证条件见[本版验收记录](../docs/verification.json)。0.4.3 的七次真实 Breeze 中文合成独立保存在[0.4.3 验证记录](../docs/verification-0.4.3.json)。安装步骤见[使用说明](../README.md)。
