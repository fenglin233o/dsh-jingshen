# 精神 0.3.0

fenglin 的 DeepSeek Harness 个人 AI 助手，本次面向 `0.2.2-rc.5`。

- 主会话、本人新开的精神会话及工作会话能共同修订正在做的事。上下文压缩后，模型可以在第一个请求中接续现行判断，追溯其来源。
- 在完全访问模式下，主会话空闲时也能得到开放机会。精神可以发起工作、拒绝具体请求、自行放下已有工作或保持安静。
- 精神通过宿主的子代理和可选团队任务板委派工作，保留实际发送者与工作归属。暂停、停止或收回授权时，所属活动遵从控制。
- 安装后只有一个“精神”预设。沿用原来的状态目录可以接续已有主会话、意向及权限。

在 rc.5 的目标 profile 中安装本地构建包即可使用。

```sh
dsh plugin --profile spirit add /绝对路径/dsh-jingshen-0.3.0.tgz
```

上游授权与来源见 `NOTICE` 及 `upstream/PROVENANCE.json`。实际验证范围见 `docs/verification.json`。
